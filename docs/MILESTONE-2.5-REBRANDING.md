# Milestone 2.5: Velasia Airways rebranding

The fictional airline formerly called **AeroNova** is now **Velasia Airways**. Its tagline is
**Beyond every horizon.** This milestone changes identity and presentation only. Search,
inventory, scheduling, and pricing logic are untouched, and no Milestone 3 features were added.

## Brand decisions

| Decision         | Choice                                                                                                                                           |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| Name             | Velasia Airways (short form: Velasia). Fictional, headquartered in the Philippines, sells in PHP, English.                                       |
| Symbol           | Two swept wing blades form a V on a shared horizon line. The gold trailing blade climbs past the frame. A geometric original, not clip art.      |
| Wordmark         | VELASIA / AIRWAYS in outlined Manrope; AIRWAYS is justified to the width of VELASIA.                                                             |
| Palette          | Midnight Navy `#101E38` and Deep Navy `#172B49` carry the brand. Warm Gold `#EFB86A` is for selective emphasis. Content stays on light surfaces. |
| Typography       | Manrope for display (it matches the wordmark) and Inter for text. Plus Jakarta Sans was retired.                                                 |
| Primary action   | Gold button with navy text (9.3 : 1). One per view.                                                                                              |
| Flight numbers   | Customers see `VEL 501`. Internal identifiers stay `NV501` / `NV501-20261215`. Velasia claims no IATA or ICAO designator.                        |
| Default metadata | Title `Velasia Airways \| Beyond Every Horizon`, with the description given in the brief.                                                        |

Full usage rules are in [BRAND-GUIDELINES.md](BRAND-GUIDELINES.md).

## Asset inventory

`apps/web/public/brand/`: `velasia-symbol.svg`, `velasia-logo.svg` (primary), `velasia-logo-light.svg`
(one colour), `velasia-logo-dark.svg` (reversed), `velasia-wordmark.svg`, `velasia-favicon.svg`,

All of them, plus `apps/web/src/components/brand/logo-geometry.ts`, are generated by
`scripts/brand/generate-brand-assets.mjs` from one geometry definition. Its tools (opentype.js,
`@fontsource/manrope`, sharp) are not workspace dependencies; see the script header. The old
`apps/web/src/app/icon.svg` (the AeroNova "nova" mark) was removed.

## Frontend changes

- **Identity:** `Logo`/`LogoMark` render the generated geometry inline (no request, crisp at any
  size) in the header, footer, mobile menu, and flight-results carrier mark.
- **Design tokens** (`packages/ui/src/theme.css`): the `navy-*` names are unchanged but remapped
  to the brand navies. `ember-*` was replaced by a contrast-annotated `gold-*` scale. Surfaces,
  ink, lines, and the focus colour follow the brief. The badge tone `ember` became `gold`, and the
  `primary` button became gold.
- **Homepage:** the hero headline is the tagline, with a gold horizon arc at its base and a gold
  marker on "Book a flight". The section structure is unchanged. The footer gains a gold horizon
  rule; the mobile menu gets a symbol watermark and a gold CTA.
- **Flights (M2 UI):** the carrier mark and name read "Velasia" with `VEL` numbers on cards,
  details, and review. Empty states ("Velasia doesn't fly from…") use the shared config. The
  stops, layover, and low-seat accents moved to gold shades that keep AA contrast.
- **Metadata:** a new `pageMetadata()` helper builds a canonical URL plus Open Graph and Twitter
  tags for each page, so no page loses the social card (Next replaces nested `openGraph` instead
  of merging it). Canonical paths are unchanged. Added: SVG favicon, Apple touch icon,
  `manifest.webmanifest`, and theme colour `#101E38`.
- **Copy:** every visible "AeroNova" now reads Velasia Airways or Velasia, including help, about,
  manage booking, fares preview, error and global-error pages, and the demo notice. The about
  page now states that the airline holds no designator.
- The search draft's `localStorage` key moved from `aeronova:search-draft` to
  `velasia:search-draft`. An unsent draft from before the rebrand is not carried over.

## API identity changes

- `airline` in `@velasia/contracts` is the single source for name, short name, tagline, country
  (`PH`), currency (`PHP`), display prefix (`VEL`), `isFictional`, and the disclaimer.
  `displayFlightNumber()` and `formatFlightNumber()` derive the customer-facing number from it.
- New, additive `GET /v1/airline` serves that identity (`airlineIdentitySchema`).
- `/health` now reports `service: "velasia-retailing-api"`.
- Fixture copy (the Manila "home hub" line), validation messages, and code comments now name
  Velasia.
- Test-only plumbing was renamed: the `x-velasia-fault` header, the `velasia-fault` cookie, and
  `VELASIA_TODAY`. `AERONOVA_TODAY` is still read as a deprecated alias, so existing local
  `.env` files do not silently lose their pinned date.

## Repository migration

The repository was renamed from `nextrs-sh/aeronova` to **`nextrs-sh/velasia-airways`**, and the
local checkout was moved to `BOOKSPINE/velasia-airways`. Checks done before the rename: the
target name was free, the owner has admin access, there were no open PRs, and the repo had no
webhooks, deployments, Pages site, or environments. CI uses only `actions/checkout` with no
hardcoded repository name, and no tracked file contained the old repository URL.

For anyone with an existing clone:

```bash
git remote set-url origin https://github.com/nextrs-sh/velasia-airways.git
pnpm install   # pnpm's .bin shims hold absolute paths; reinstall after moving a checkout
```

GitHub redirects the old URL for git and web traffic, but do not rely on that indefinitely.
Re-creating a repository named `nextrs-sh/aeronova` would break the redirect. Update any
external bookmarks, badges, or integrations added later.

## Remaining issues

- The mark has had no trademark clearance. It is suitable for this fictional demo only.
- `VEL` is a display convention, not a registered designator. The internal `NV` prefix stays
  until a data migration milestone, if ever.
- The `AERONOVA_TODAY` alias should be removed in M3.
- Lighthouse and a manual screen-reader pass were not run for this milestone. Coverage relies
  on axe in E2E and on the contrast-checked tokens.
